## Purpose and publication boundary

This is a public documentation and planning workspace for [Zion Tech Group](https://ziontechgroup.com). It connects Discovery benefits, intake, commercial review, rollout decisions, the reviewed app directory, and clear promotional language. Publication of these Markdown files is not deployment of the company website, a production application, a questionnaire backend, or an email workflow.

The catalog is complete for the three reviewed directory/showcase snapshots described below. It is not an assertion that every route on the entire website, every historical concept, or every deployed application has been inventoried. Private operational histories from different connected accounts are not merged into this public documentation.

## Boundaries that apply everywhere

- A published route is not a tested app; a reading link is not an implemented integration.
- A generated report is not a guaranteed financial result, certification, diagnosis, staffing reservation, or purchase authorization.
- This documented rollout keeps questionnaire access and the client-safe summary free. Source pages contain inconsistent free versus paid Discovery language; reconcile the actual offer before customer commitments. Do not infer that every engagement labeled Discovery is free.
- Optional consulting or implementation requires a separate written scope. No automatic paid conversion is described or installed.
- Keep personal data, credentials, private page links, mailbox/CRM exports, supplier costs, and private memory payloads out of public changes.
- Described routing through commercial@ziontechgroup.com is a workflow requirement, not a claim that an email was sent or delivered.
